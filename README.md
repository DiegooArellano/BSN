# Sitio Web Corporativo - Bufete en Soluciones de Normatividad S.A. de C.V. (BSN)

Rediseño integral para Unidad de Información Comercial acreditada por la EMA y aprobada por la DGN.

## Estructura de archivos
- `index.html`: Estructura semántica completa, logotipo y escudo BSN vectorizado, carrusel de 3 slides y subpáginas.
- `styles.css`: Estilos personalizados, transiciones de vistas y estados activos.
- `app.js`: Lógica del carrusel, buscador/filtro en tiempo real de las 9 NOMs y widget de WhatsApp.

## Despliegue / Uso local
1. Descomprime el archivo `.zip`.
2. Abre `index.html` en tu navegador o levanta un servidor local (por ejemplo con Live Server en VS Code).
3. Para ponerlo en producción en el dominio `uva-bsn.com.mx`, sube estos 3 archivos a la raíz (`public_html` o similar).
